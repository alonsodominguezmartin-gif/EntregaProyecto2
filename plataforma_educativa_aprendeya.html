Sobre este curso

Domina los fundamentos de desarrollo web cliente desde cero. Aprenderás maquetación semántica con HTML5, sistemas de diseño flexibles con CSS Grid y Flexbox, así como programación JS pura para cliente.

Temario del Curso

Módulo 1: HTML5 Semántico y Arquitectura Web
Estructuración de documentos, etiquetas de sección, accesibilidad web y mejores prácticas SEO.
Módulo 2: Estilos Modernos con CSS Grid y Flexbox
Estrategia Mobile First, variables CSS (:root), animaciones y diseño completamente responsive.
Módulo 3: Lógica Cliente con JavaScript (ES6+)
Manipulación del DOM, eventos, estado local y estructuración de aplicaciones Single Page (SPA).
